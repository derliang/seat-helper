# 🪑 座位小幫手 (Seat Helper)

> **智慧型教室座位編排系統**  
> 專為教師打造，具備三步驟智慧抽籤、併排雙人桌設定與多格式檔案匯出功能。

👉 **[點此開啟線上正式版 (GitHub Pages)](https://derliang.github.io/seat-helper/)**

### ⚡ v2.7 (2026-08-01) - 3 步驟智慧型抽籤與併排設定版 [目前基準 Baseline]
- **三步驟 SOP 工作流**：匯入名單 ➔ 個別需求設定 ➔ 執行分階段抽籤。
- **四大個別需求標籤**：坐靠前 (Emerald)、坐靠後 (Slate)、不最後 (Purple)、不靠邊 (Amber)。
- **併排 (雙人桌) 動態開關**：自由切換雙人桌/單人桌合併連線。
- **5 大美化匯出格式**：支援複製圖片、下載 PNG、PDF、Excel 與 Word。
