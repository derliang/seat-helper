# 🪑 座位小幫手 (Seat Helper)

> **智慧型教室座位編排系統**  
> 專為教師打造，具備三步驟智慧抽籤、併排雙人桌設定與多格式檔案匯出功能。

👉 **[點此開啟線上正式版 (GitHub Pages)](https://derliang.github.io/seat-helper/)**

## 📜 完整版本演進歷程 (Version History & Changelog)

- **🔒 取消 Google/Cloud 並恢復純本機安全模式 (FIX-18F)**：依據使用者最新決策，取消目前版本的 Google SSO、OAuth、Sheets API、Cloud AutoSave 與 Cloud 雙模式。完整移除所有 Google SDK 與驗證標籤，恢復 LocalStorage 為唯一自動儲存來源，並解除齒輪登入鎖定，保持純 Lucide `settings` Icon 獨立按鈕。
- **⚙️ 獨立本機管理後台骨架 (TODO-23)**：設定齒輪可切換至全螢幕 `#adminView`，並可安全返回抽籤主頁；切換過程不重建座位與抽籤狀態。
- **🏫 班級與教室名稱 (TODO-24, FIX-24A)**：後台可設定並以 LocalStorage 記住班級名稱，同步顯示於頁面與座位表預覽區頂端，並套用至 PNG、PDF、Excel、Word 匯出檔名。
- **🔊 五階段抽籤音效設定 (TODO-25, FIX-25A/B/C)**：後台改為響應式區塊介面，五個抽籤階段可分別從 10 種 Web Audio 音效中選擇、試聽與本機保存，並提供全域開啟／靜音控制。
- **📦 JSON 完整備份與還原 (TODO-27)**：後台可匯出包含名單、座位、班級、音效與主題的完整本機備份；匯入時先驗證檔案並經二次確認才覆蓋現有資料。
- **🧩 座位表顯示內容設定 (TODO-31)**：後台可分別控制頁面預覽與匯出檔案的班級名稱、大屏、排名、座標、需求、禁排、空座位及日期；常用設定置前、JSON 備份置底，Header 工具按鈕靠左。
- **💣 完整清除本機資料 (TODO-28)**：修正 LocalStorage key，經兩次確認後清除名單、座位、需求、歷史與所有本機設定並恢復預設值，不影響同網域其他程式資料。
- **⚙️ 設定齒輪純 Icon (TODO-18, FIX-18A~D)**：設定按鈕純 Icon 化，深色模式與設定按鈕對齊座位設定區最右側；取消登入鎖定。

### ⚡ v2.7 (2026-08-01) - 3 步驟智慧型抽籤與併排設定版 [目前基準 Baseline]
- **三步驟 SOP 工作流**：匯入名單 ➔ 個別需求設定 ➔ 執行分階段抽籤。
- **四大個別需求標籤**：坐靠前 (Emerald)、坐靠後 (Slate)、不最後 (Purple)、不靠邊 (Amber)。
- **併排 (雙人桌) 動態開關**：自由切換雙人桌/單人桌合併連線。
- **5 大美化匯出格式**：支援複製圖片、下載 PNG、PDF、Excel 與 Word。
