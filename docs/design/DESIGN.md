# 座位小幫手：設計規範

> 狀態：定案（v3.3.0 方案 1b；v3.4.0 加入第八九節標示與三項優化，採 1a 筆刷＋2a 角標）。最後更新：2026-11-06。改任何頁面、版面、元件、樣式前先讀這份。要偏離，先更新本文件並取得使用者確認。

- 定案的模擬頁：`docs/design/mockups/改版稿-第1輪.html`（含 1a、1b 兩案與後台；實作採 1b）
- v3.4.0 的模擬頁：`docs/design/mockups/第八九節標示與三項優化.html`（第八九節標示的筆刷與逐人面板兩案、設定頁、匯出樣貌、併桌、特殊需求 2a／2b、抽籤名單；實作採筆刷與 2a）
- 範圍：只改視覺與版面，不改功能、資料格式、匯出流程。所有 `id` 與 inline handler 名稱維持不變。
- 實作位置：`index.html` 的 `<style>` 前段（tokens 與元件）。`seat_helper.html` 必須同步成同一份。

## 1. 設計原則

1. **座位表是主角。** 步驟、狀態與匯出都圍繞它排；座位表永遠在桌機左側、iPad 上方。
2. **一次只做一件事。** 名單、需求、抽籤用分頁切換，不同時攤開，降低第一次使用的學習成本。
3. **狀態看得出來。** 步驟完成打勾、抽籤階段標示已完成、統計列顯示進度條，不靠使用者記憶。
4. **用 token，不寫死。** 顏色、圓角、陰影一律來自 `:root` 的變數；深色靠 `html.dark` 覆寫同一組 token。
5. **匯出是列印用途。** PNG／PDF 一律強制淺色（擷取時暫時拿掉 `dark`）。

## 2. Tokens

### 色彩（淺色／深色）

| token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#F5F2EA` | `#13120E` | 頁面底 |
| `--surface` | `#FFFDF8` | `#1C1A15` | 卡片、導覽、座位表紙面 |
| `--sunken` | `#F1EDE3` | `#17150F` | 凹陷底（輸入框、統計列、空位） |
| `--line` / `--line-2` | `#E4DECF` / `#CFC7B2` | `#302D24` / `#433F33` | 分隔線／控制項邊框 |
| `--text` / `--text-2` / `--text-3` | `#22201B` / `#4F493D` / `#6F6858` | `#F1EDE2` / `#CFC8B6` / `#A0987F` | 主要／次要／輔助文字 |
| `--accent` | `#274690` | `#3F63C4` | 主色（墨藍）；白字對比 ≥ 5:1 |
| `--accent-soft` / `--accent-ink` / `--accent-line` | `#E8EDF8` / `#1F3877` / `#B9C6E6` | `#1B2540` / `#AFC2F5` / `#33467E` | 主色淡底、文字、邊框 |
| `--danger` 系列 | `#E11D48` 等 | 見 `html.dark` | 清除、禁排、錯誤 |

座位需求的**語意色**固定，兩種主題都有 `-bar`（色點）、`-soft`（底）、`-line`（邊）、`-ink`（字）、`-fill`（實色按鈕）：

| 類別 | token 前綴 | 色相 |
|---|---|---|
| 靠前 | `--pri-` | 翠綠 |
| 靠後 | `--rear-` | 石板灰 |
| 不最後 | `--nb-` | 紫 |
| 不靠邊 | `--ns-` | 琥珀 |
| 其他人 | `--nm-` | 靛 |

第八、九節**「章」**不佔用上面五個需求色，用黑白兩色：`--att-fill`／`--att-on`（實底章與其字）、`--att-soft`／`--att-ink`／`--att-line`（空心章）。深色時黑白對調。圓角彩色膠囊＝需求，方角黑白章＝第八九節，兩種資訊分開，黑白列印也分得出來。

同一類需求在各處要長一樣：需求表按鈕（`.tag-toggle.active`）、座位卡角標（`.need-pill`）、抽籤名單（`.nm`）都用 `--c-bar／-soft／-line／-ink／-fill` 這組區域變數（由 `.status-*`、`.ph-*` 設定）。

> **只准用十六進位色碼。** 匯出使用 html2canvas 1.4.1，不支援 `oklch()`、`color-mix()`，用了會讓 PNG／PDF 失敗。

### 字型

| 用途 | 字型 | 字級／字重 |
|---|---|---|
| 標題（頁面、卡片、座位表標題、統計數字） | Noto Serif TC，後備 Noto Sans TC | 16–22px／700 |
| 內文、按鈕、表單 | Noto Sans TC | 14px／500–700 |
| 輔助、標籤 | Noto Sans TC | 12px／700 |

數字欄一律 `font-variant-numeric: tabular-nums`。不使用斜體與 900 字重。

### 間距、圓角、陰影、動態

- 間距以 4px 為單位：4、8、12、16、20、24、32。
- 圓角四級：`--r-sm` 8、`--r-md` 12、`--r-lg` 16、`--r-xl` 24。原本 32–56px 的大圓角不再使用。
- 陰影三級：`--shadow-1`（卡片）、`--shadow-2`（座位表紙面）、`--shadow-3`（對話框）。
- 動態：互動 150ms；座位落下 450ms；抽籤儀式動畫維持原樣。`prefers-reduced-motion` 時縮到幾乎無動畫。

## 3. 版面與斷點

| 寬度 | 版面 |
|---|---|
| 桌機 ≥1024 | 兩欄：左座位表（含統計、設定、圖例、匯出），右「步驟」面板（名單／需求／抽籤分頁，右欄吸頂） |
| iPad 640–1023 | 單欄：座位表在上，步驟分頁在下 |
| 手機 <640 | 單欄，底部固定四個分頁：名單、需求、抽籤、座位表；一次只顯示一個 |

- 目前步驟存在 `#mainView[data-step]`（list／needs／draw），手機的「座位表」分頁存在 `data-tab="map"`；由 `setStep()`、`setTab()` 切換。
- 匯入名單成功會自動切到「需求」。

## 4. 元件規則

- **按鈕**：`.btn`（次要）、`.btn-primary`（每個畫面只有一個主要動作）、`.btn-danger`（淡紅，清除類）、`.btn-nuke`（全部重設，黑白反相高對比）、`.btn-ghost`、`.btn-sm`、`.btn-lg`。最小高度 40px，手機點擊區 ≥44px。
- **圖示按鈕**：`.icon-btn` 40px。
- **表單**：`.input`、`.label`、`.sw`（開關，仍是 checkbox）、`.check`、`.stepper`、`.seg`。
- **卡片**：`.card`；步驟卡 `.step-card`，標題列含步驟編號 `.num`（完成時顯示勾）、標題、副標、清除按鈕。
- **座位卡**：`.seat-card`。淡底色，**不使用左側色條**。狀態類別 `status-priority／rear／noBack／noSide／normal`、`seat-empty`（虛線）、`seat-disabled`（斜紋）；併排用 `mg-l／mg-r／mg-m`。座號在上、姓名在下。
  - **特殊需求角標（2a）**：有需求的卡（`.has-needs`）左上角是實色膠囊 `.need-pill`（字用需求表按鈕的「靠前／靠後／不後／不邊」），外框 2px 需求色；一般卡仍是左上 `.seat-indicator` 色點。「個別需求標示」關閉時（`hide-needs`）恢復淡底與色點。
  - **第八九節章**：`.att`（`att-both` 實底「無8·9」、`att-nine` 空心「無9」、`att-part` 虛線「無9 一三」），置於卡片底部置中；卡片寬 ≤62px 時隱藏星期（`att-compact`）。有人標示時座位表加 `.has-att-seats`，卡片略加高。
- **標示筆刷列（1a）**：座位圖例列右側「標示第八、九節」開關 `#btnMarkMode`；進入標示模式後出現 `#brushBar`（沒上第八節／每天不上第九節／指定星期＋一二三四五／清除標示／完成標示），座位表外框變主色。點座位套用筆刷、再點同筆刷取消；標示模式下點座位不開指定學生選單。手機版筆刷列固定在底部分頁上方。匯出時暫時拿掉標示外框。
- **需求表模式**：步驟 2 表格上方 `.seg`「需求｜第8·9節」；第8·9節模式每列「第八節 不上」開關 `.mk8` 加週一至週五 `.dchip`，亮起＝不上；不上第八節時第九節五天鎖定。手機每人兩行，按鈕 ≥44px。
- **座位表下方章說明**：`#attLegendDisplay` 在擷取區內，只列這張表用到的章，隨匯出一起輸出；後台「座位表顯示內容」的「第八、九節標示」可分別關閉預覽與匯出。
- **併排設定**：整列是 `<details class="merge">` 的按鈕：左圖示塊、標題、副標（已併哪幾排）、縮圖 `.mg-mini`、右側有字的「展開設定／收合」膠囊 `.mg-act`；展開時標題列變淡藍底。內容仍是同一行排名（`.merge-row`，窄螢幕橫向捲動），排與排之間圓形連接鈕（`.merge-btn`）；每顆各自切換，連續點可三排、四排。展開時獨占一列；手機連接鈕 44px。
- **抽籤階段**：`.phase`，內含 `.ph-ic`、`.ph-t`、`.ph-m`、`.ph-btn`（內有 `.lbl-go`、`.lbl-done`）、`.names`。`.finished` 表示已完成。名單標籤 `.nm` 用該階段的需求色：待抽＝淡底＋色點，已定位 `.set`＝實色底白字並附座位；沒人需要 `.none` 為虛線灰。
- **對話框**：`.modal`（桌機置中、手機貼底）；遮罩 `#modalOverlay`。
- **提示**：`#copySuccess`、`#customAlert`、`#drawStatusBanner`。
- **空狀態**：`.empty-st`，說明下一步要做什麼。

## 5. 頁面規則

- **主畫面**：見 §3。匯出區在座位表下方，「複製圖片」為主要按鈕，其餘一律次要樣式。
- **後台**：左側目錄（桌機）／橫向標籤列（手機），單欄內容卡，順序：基本資料、座位表顯示、抽籤偏好、抽籤儀式、身高資料、Word 模板、備份、後台 PIN。程式不再於開啟時重排區塊。
- **匯出擷取區** `#captureArea`：維持原有子元素 `id`；顯示設定的 `hide-*` 類別行為不變。

## 6. 文案語氣

台灣繁體中文。按鈕寫動作（「匯入並進行下一步」「儲存結果」）。清除類按鈕帶「清除」二字，不只放垃圾桶圖示。

## 7. 無障礙

文字對比至少 4.5:1；手機點擊區至少 44px；所有可操作元素有可見的 `:focus-visible` 外框；座位卡可用 Tab 與 Enter／空白鍵操作。

## 8. 不要做的事

- 不在畫面或 JS 產生的標記裡寫死色碼、斜體粗字（`italic font-black`）、大圓角。
- 不使用 `oklch()`／`color-mix()`（匯出會壞）。
- 不用左側色條標示分類。
- 不把座位表以外的內容放進 `#captureArea`（會被匯出）；頁面不放版權文字，版權標示只在原始碼頂端的 HTML 註解。
