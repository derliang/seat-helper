## 2. 兩份真實檔的結構歸納（已去識別化）

### 2.1 檔案甲（上學期）

- **2 個工作表，一個班級一張**；工作表名稱就是班級名稱（沒有「班級」欄）。兩張表版面完全相同。
- 第 1 列：**各成績欄上方的比重列**（文字「10%」「15%」「20%」），只出現在成績欄上方，姓名等欄位上方是空的。
- 第 2 列：標題列。欄位依序為：`組別`、`座號`、`姓名`、5～6 個活動／作業成績欄（欄名是活動名稱，不是「第一次段考」這類）、`○○平均`（部分欄的平均，公式）、**空白分隔欄**、`原始成績`（比重加權，公式）、`學期成績`（原始成績依全班平均換算，公式）。
- 第 3～36 列：34 位學生，座號 1～34 連號無缺漏。
- 第 37 列：**統計列**，第 1 欄寫「平均」且與前三欄**合併儲存格**，座號與姓名空白，成績欄是 AVERAGE 公式。
- 成績欄是整數（90、80、70、60 這種級距）與少數小數；**有些格子空白**（沒有那次成績），AVERAGE 會自動忽略空白。
- `組別` 欄是 1～10 的整數，每個數字重複 3～4 次（＝當學期分組結果）；`座號` 欄則是 1～34 各出現一次。
- 標題儲存格被設成「日期」格式（顯示格式含「月」「日」），但**內容是文字**，不是日期。
- 姓名全是 3 個中文字，無重複、無前後空白、無全形字元、與另一班無重名。
- 公式儲存格都有存計算結果（快取值），讀得到數字。

### 2.2 檔案乙（下學期）

- **5 個工作表**，其中四張是「同一批學生的不同版本」：
  1. **彙總表**：1 列標題、之後每人一列；**兩個班級左右並排**成兩個區塊（各自有班級、分組、座號、姓名、四個段考／平時成績欄、學期成績），中間隔一個空白欄，右區塊欄位完全重複一次。每列都有班級欄（整欄同值）。沒有統計列。凍結首列。最後一欄「學期成績」是公式（各成績欄加權），快取值為數字。欄名**把比重寫在欄名裡**（例如「某某15%」「平時50%」）。
  2. **班級甲的輸入表**、**班級乙的輸入表**：成績欄填的是**等第（A／B／C）與「缺」「假」**，另有一欄「加扣分」（只有少數人有值，3 或 6）。表尾「平均」統計列同樣是合併儲存格。因為成績是文字，**後面的「原始成績」「學期成績」公式整欄算出錯誤值**（快取值是 `#VALUE!`，統計列是 `#DIV/0!`）。第 1 列是**小數比重**（0.3、0.2…，存成百分比格式）。
  3. **班級甲的結算表**、**班級乙的結算表**：與輸入表版面相同，但等第已換成數字（A→95、B→85、C→75；缺→60、請假→85；輸入表空白的成績格換成 95），公式正常、有數值。
- 工作表的「已使用範圍」被延伸到 1000 列（只有格式、沒有資料），讀取時若不裁掉尾端空列，會讀到近千個空列。
- 成績欄裡出現：整數、小數（有的是長達十幾位的小數，例如平時成績算出來的平均）、`A`／`B`／`C`、`缺`、`假`、空白、錯誤值。
- 沒有隱藏欄、隱藏列、註解、資料驗證；有一個條件式格式（與讀資料無關）。

### 2.3 兩份檔案之間

- 兩個班級在兩份檔案裡的學生**完全相同**：每班 34 人，姓名全部對得上，**座號也全部相同**。
- 兩個班級之間**沒有重名**，但**座號會重複**（兩班都有 1 號、2 號…）→ 要辨識一個學生必須用「班級＋座號」或「班級＋姓名」，**不能只用座號**。
- `組別` 欄兩個學期幾乎不同（34 人裡只有 3 人兩次同組）→ 老師會輪換分組。**檔案裡的「組別」欄＝上一次的分組結果**，正好是「避免與上次同組」需要的資料（見 5.7）。
- 檔案乙的彙總表與班級表的組別一致（34／34、32／34），彙總表是從班級表整理出來的，**同一批人在不同工作表重複出現**。

### 2.4 從這兩份檔歸納出的規律（編號供測試與實作對照）

| 編號 | 規律 | 對智慧匯入的意義 |
|---|---|---|
| O1 | 一個檔案多個工作表；工作表名稱＝班級名稱 | 要讓老師選工作表；沒有班級欄時用工作表名稱當班級 |
| O2 | 同一批人出現在多個工作表（彙總＋各班＋結算版） | 預設只選一張，否則人數會重複算 |
| O3 | 標題列不在第 1 列，上方有**比重列**（文字 `10%` 或小數 `0.3`） | 標題列要用內容判斷；比重列不是標題、也不是學生 |
| O4 | 比重也可能寫在欄名裡（`某某15%`） | 欄名要能拆成「名稱＋比重」 |
| O5 | 同一張表**左右並排兩個班級**，標題重複 | 要能偵測重複標題並切成多個區塊 |
| O6 | 欄位順序不固定：`組別` 在 `座號` 前；`班級` 有時在最前 | 不能靠位置，要靠欄名＋內容 |
| O7 | `組別`（1～10，重複）與 `座號`（1～N，不重複）都是小整數 | 用「是否每個值只出現一次」區分 |
| O8 | 表尾有**統計列**（「平均」，合併儲存格，座號與姓名空白） | 姓名欄不像姓名的列一律不算學生 |
| O9 | 尾端有近千個只有格式的空列 | 裁掉尾端空列 |
| O10 | 空白分隔欄、空白欄 | 分隔欄不是成績欄 |
| O11 | 一人多個成績欄；最右邊有計算好的總成績（`原始成績`、`學期成績`），中間還有「部分平均」欄 | 要猜哪一欄是總成績；不能看到「平均」就選 |
| O12 | 計算欄是公式；有快取值 | 讀快取值即可；沒有快取值要提示 |
| O13 | 成績欄是等第（A／B／C）＋「缺」「假」 | 要有等第換算與缺考／請假處理 |
| O14 | 公式欄整欄是錯誤值（`#VALUE!`、`#DIV/0!`） | 錯誤值當「沒有成績」，整欄都錯就不能選 |
| O15 | `加扣分` 欄：多數人空白，少數人有 3、6 | 不是成績欄；填寫率低的欄不能當預設成績 |
| O16 | 空白成績格 ≠ 一定是缺考（老師的輸入表裡空白＝預設 A） | 空白一律顯示為「沒有成績」，讓老師在補輸入步驟決定；不要擅自補 |
| O17 | 老師自己的缺考／請假換算不一致：缺→60、請假→85 | 缺考／請假的換算要讓老師逐項選，不能內建單一規則 |
| O18 | 標題儲存格有日期格式但內容是文字 | 讀標題一律當文字，不依格式猜日期 |
| O19 | 兩個學期姓名＋座號都對得上 | 跨檔對應以「班級＋姓名」為主、座號為輔 |
| O20 | `組別` 欄＝上次分組 | 可匯入成「避免同組」的比對對象 |

## 3. 另一批「常見但這兩份檔沒出現」的髒資料（我的建議，非檔案內觀察）

> 這些是教學現場很常見、值得先防的狀況。標「我的建議」，實作時視額度取捨（見第 8 節）。

| 編號 | 狀況 | 容錯做法 |
|---|---|---|
| C1 | CSV 用 Excel 存成「CSV（逗號分隔）」在繁體 Windows 是 Big5 編碼，用 UTF-8 讀會亂碼 | 先嘗試 UTF-8（嚴格），失敗改 Big5（`TextDecoder('big5')`）；有 BOM 去掉 |
| C2 | 多層表頭（上層是「第一次段考」合併儲存格，下層是「國文」「數學」） | 合併儲存格內容往右填滿，上下層用「｜」串成一個欄名 |
| C3 | 成績寫成文字數字：`" 85 "`、`85分`、全形 `８５`、`85.5` | 去空白、NFKC 轉半形、去「分」 |
| C4 | 百分比：儲存格格式 `0%`（值 0.85）或文字 `85%` | 整欄值都在 0～1 且格式為百分比→乘 100；文字 `%` 去掉符號 |
| C5 | 缺考／請假的各種寫法：缺、缺考、曠、請假、假、公假、病假、免、補考、待補、`-`、`/`、`--`、`N/A` | 一律視為「沒有成績」，並在預覽以原文標示（缺／假），老師可逐項改成換算分數 |
| C6 | 學號與座號：學號是 5～8 位的長數字（如 11203），座號是 1～2 位 | 長數字欄不當座號；預設略過，並提供「用學號後兩碼當座號」選項 |
| C7 | 姓名內有空白（`王 小明`、`王　明`）、姓名後註記（`(轉出)`、`*`、`★`） | 去空白；註記只提示、不自動刪（避免誤刪） |
| C8 | 同班同名 | 都保留（以座號區分）並提示「有 2 位同名，座號 x、y」；完全相同（座號、姓名、成績都一樣）的重複列才合併 |
| C9 | 轉出／轉入學生被隱藏列或刪除線 | 預設略過隱藏列並提示筆數，可勾選納入 |
| C10 | 檔案公式沒有快取值（程式產生、未用 Excel 開過存檔） | 成績欄是公式但讀不到值→提示「這個檔案沒有存計算結果，請用 Excel 或 Google 試算表開啟後另存再匯入」 |
| C11 | 隱藏的工作表 | 預設不列入選擇（或列出但標「隱藏」，不預選） |
| C12 | 班級寫法不一致：`3A`、`3a`、`三年A班`、`3 A` | 只做全半形與前後空白、英文大小寫正規化；不做語意轉換（不猜「三」＝3） |
| C13 | 成績超出 0～100（如 101、-3、1000 打錯） | 不擋，列警告「有 N 個成績不在 0～100」並標紅該列 |
| C14 | 沒有標題列 | 完全用內容判斷欄位角色（見 5.3 的內容判斷） |
| C15 | 整頁是標題橫幅（「○○中學 ○年○班成績表」合併儲存格）在表格上方 | 標題列判斷只看前 15 列中「最像標題」的一列，橫幅列因為只有 1 個非空格會被淘汰 |
| C16 | 分頁列印用的重複標題列夾在資料中間 | 資料區出現與標題相同的列→略過並提示 |

## 4. 智慧匯入方案（管線）

把所有來源（xlsx／xls／csv／貼上）統一成「工作表清單」，再走同一條判斷管線；每一步都產生**可見的判斷結果**與**依據**，不確定的地方標出來讓老師改，不要默默猜。

```
讀檔 → 篩工作表 → 切區塊 → 找標題列 → 判欄位角色 → 篩資料列 → 選成績欄與合併 → 轉成績 → 決定班級 → roster + 報告
```

### 4.1 中立資料格式（解析層的輸入，與讀檔函式庫脫鉤）

```
sheet = { name, rows: [[cell…]…], merges: [{r1,c1,r2,c2}…], hiddenRows: Set, hiddenCols: Set,
          hidden: bool, pct: Set<"r,c">（格式為百分比的儲存格） }
cell  = null（空）| number | string | { err: '#VALUE!' }（Excel 錯誤值）| { formulaNoValue: true }（公式沒有計算結果）
```

- **轉接層**（`fromSheetJS`）只有一個很薄的函式：`XLSX.read` 後逐格走訪，把 `t:'e'` 轉成 `{err}`、有 `f` 沒 `v` 轉成 `{formulaNoValue}`、合併範圍與隱藏列欄抄進去、**合併儲存格不在這裡展開**（交給 4.4 的標題展平）。
- 解析層（純邏輯）**只吃中立格式、不碰 DOM、不依賴 SheetJS**，才能用 node 直接測，測試資料用二維陣列捏造即可（不需要真的 xlsx 檔）。
- 貼上與 CSV：切分成 `rows`（Tab 優先、其次逗號、全形逗號、多個空白），當成只有一個工作表。

### 4.2 工作表選擇（O1、O2、C11）

1. 略過隱藏工作表與沒有資料的工作表。
2. 每張表算「名單分數」：能找出的姓名欄人數、成績欄數量與可用比例、公式錯誤比例。
3. 找**重複工作表**：兩張表的姓名集合重疊 ≥ 80%（比對 3 位數以上的人名，過小的集合不比）→ 視為同一批人的不同版本，**只預選品質最高的一張**（可用成績欄最多、錯誤值最少、有班級欄優先），其餘標「與『X』重複，未選」。
4. 結構相同但姓名**不重疊**的多張表（檔案甲）→ 各是一個班級，**一起預選**，班級＝工作表名稱。
5. 老師可在預覽上方改選（勾選方塊）；選了多張就合併成一份名單。
- 檔案甲 → 預選 2 張（兩個班級）；檔案乙 → 預選彙總表 1 張（含兩個班級），另 4 張標為重複。

### 4.3 區塊切分（O5、O10）

- 在標題列上，若同一列有 ≥ 2 個「姓名」欄名，或以整欄空白隔開、且每段都有姓名欄 → 切成多個區塊，每塊當作一張獨立的表（班級欄各自帶）。
- 檔案乙彙總表因此變成兩個區塊、共 68 人。

### 4.4 找標題列（O3、O4、O18、C2、C14、C15）

1. 在前 15 列中，每列算分：符合欄名詞庫（班級、班別、座號、號碼、學號、姓名、成績、平均、總分、組別、分組、小計…）的格數；整列必須至少 2 個不同的文字格。
2. 取最高分列當標題列。分數相同取靠下的（橫幅標題在上）。
3. **比重列**：標題列正上方一列，若只有成績欄上方有值、且值是 `10%`／`0.3` 這類，且總和約 1 或 100 → 記為比重，不當標題也不當學生。欄名內的 `15%` 後綴同樣拆成比重（O4）。
4. **多層標題**：標題列上方還有文字列、且有合併儲存格往右跨欄 → 往右填滿後與下層串成「上層｜下層」（C2）。
5. 標題一律當文字處理（O18）。
6. 找不到標題列（最高分 < 2）→ 進入 C14：完全用內容判斷欄位角色。

### 4.5 判斷欄位角色（O6、O7、O10、O15、C6）

每欄給一個角色與信心（高／中／低）：`班級`、`座號`、`姓名`、`組別（上次分組）`、`成績候選`、`略過`。**欄名與內容雙重證據**，兩者衝突時信心降為「中」並提示。

| 角色 | 欄名線索 | 內容線索 |
|---|---|---|
| 姓名 | 姓名、學生、名字 | 資料列中 ≥ 80% 是 2～5 個中文字（可含「·」「．」）、重複少 |
| 座號 | 座號、號碼、座位 | 小整數（1～99）、**每個值只出現一次**、大致遞增、範圍約等於人數 |
| 組別 | 組別、分組、組 | 小整數，**同一個值出現多次**（組數遠小於人數） |
| 班級 | 班級、班別、班 | 每格是短字串，種類遠少於列數（常整欄同值） |
| 學號 | 學號 | 5 位以上的長整數；預設「略過」（C6） |
| 成績候選 | 見 4.6 | 數字（或可轉成數字、等第）占 ≥ 50%，且不屬於上面角色 |
| 略過 | 備註、加扣分、空欄 | 全空、或填寫率 < 30%（O15）、或整欄是錯誤值（O14） |

- 空白欄只當分隔（O10），不成為角色。
- 沒有班級欄、也沒有班級資訊時，班級留空（視為同一班，與 analyzeRoster 一致）。
- 檔案乙彙總表：`班級`＝班級、`分組`＝組別、`座號`＝座號、`姓名`＝姓名，四個成績候選。

### 4.6 選哪一欄當成績（O11、O12、O14、O15、O16）

**候選排序規則**（由高到低）：

1. 排除：被判為座號／組別／班級／學號的欄；填寫率 < 30% 的欄（加扣分）；整欄錯誤值的欄；整欄公式沒有結果的欄。
2. 欄名強度：
   - 強：`學期成績`、`總成績`、`學期總成績`、`總平均`、`總分`、`結算`、`最終`
   - 中：單獨的 `成績`、`平均`；`原始成績`、`合計`、`小計`
   - 弱：含「平均」但前面有限定詞（例如「某某單平均」＝只是其中幾次的平均）
3. 結構加分：是公式欄且引用同列其他成績欄（＝老師算好的總成績）；位置在所有成績欄**最右邊**。
4. 同分取最右邊。

**預設行為**：

- 找到「強」候選 → 直接選它，信心「高」（檔案甲、乙皆是：選 `學期成績`，不會誤選「某某單平均」或「原始成績」）。
- 沒有強候選但只有 1 個成績候選 → 選它，信心「高」。
- 沒有強候選、有 ≥ 2 個候選 → 預選最右邊那欄，信心「低」，黃色提示「沒有找到『總成績』欄，請確認用哪一欄」。
- 沒有任何成績候選 → 名單只有姓名（沒有成績），提示「這份檔案沒有找到成績欄，之後只能用隨機分組」。

**老師自己算好的欄優先**：欄裡已有老師算的總成績，就直接用，不重算（避免和老師公式不一致，也避免誤用我們自己的比重）。

### 4.7 多個成績欄的處理

沿用 10.1 的「解析表表頭下拉選單」：每欄可選「班級／座號／姓名／成績／略過」。**把兩欄以上設為「成績」時**，表格下方多出一行小設定：

- **合併方式**：`平均（忽略缺的）`（預設）／`依比重加權`（偵測到比重列或欄名比重時才出現，且比重加總約 100% 才預選；每人缺的欄，其比重重新分配給有成績的欄）。
- 結果仍是**單一成績欄**（10.1 使用者已裁示「名單只有單一成績欄」），合併只發生在匯入當下。
- 有人只有部分欄有成績時，警告「有 N 位只有部分成績欄，平均只用有成績的欄算」。

### 4.8 成績值轉換（O12～O17、C3～C5、C13）

逐格轉成「數字」或「沒有成績（附原因）」：

| 儲存格內容 | 處理 |
|---|---|
| 數字 | 直接用；整欄格式是百分比且值都在 0～1 → ×100（C4） |
| 文字數字（`" 85 "`、`85分`、全形 `８５`、`85%`） | 去空白、NFKC、去「分」「%」後轉數字（C3、C4） |
| 空白 | 沒有成績（原因：空白）；**不補**（O16） |
| 錯誤值（`#VALUE!`、`#DIV/0!`、`#N/A`、`#REF!`） | 沒有成績（原因：公式錯誤）；整欄皆錯誤 → 該欄不可選，並提示（O14） |
| 公式沒有計算結果 | 沒有成績；提示重新存檔（C10） |
| 缺、缺考、曠、請假、假、公假、病假、免、補考、待補、`-`、`/`、`N/A` | 沒有成績（原因：缺／假等原文），預覽以原文標示；在「缺考／請假」小面板可逐項改成「換算成 N 分」或「當 0 分」（O17、C5） |
| 等第（A／B／C、A+、甲乙丙、優良可） | 觸發「等第換算」小面板，預設表如下，可改（O13）；不套用時視為沒有成績 |
| 其他文字 | 沒有成績（原因：不是數字），列在警告裡讓老師看 |

- 預設等第換算（可改）：A 95、B 85、C 75、D 65、E 55；甲／優 95、乙／良 85、丙／可 75、丁 65。**觀察到老師自己用 A→95、B→85、C→75**，所以預設值貼近；但等第要不要換算本來就是老師的決定，**一定在預覽上顯示出換算表**，不默默換。
- 缺考／請假預設都是「沒有成績」（不猜），因為老師自己的做法就不一致（缺→60、請假→85，O17）。
- 範圍檢查（C13）：不擋，只警告。

### 4.9 資料列篩選（O8、O9、C7、C8、C9、C16）

從標題列下一列起，到最後一個有資料的列為止（先裁尾端空列，O9），逐列判斷：

1. 姓名欄為空 → 跳過（連同合併儲存格寫「平均」的統計列，O8）。
2. 姓名欄是統計詞（平均、最高、最低、合計、總計、人數、標準差、班平均、全班平均）→ 跳過；其後所有列**也停止讀取**（統計區塊之後不再有學生）。
3. 姓名欄不像姓名（含數字、A～Z 單字母、超過 6 字、整列只有標題字樣）→ 跳過並計入「略過的列」。
4. 與標題列相同的重複列 → 跳過（C16）。
5. 姓名清理：前後空白、全形空白去除；2 字以上姓名中間的空白去除；NFKC（C7）。
6. 同班同名同座號且資料相同 → 合併為一筆並提示；同班同名不同座號 → 都保留並提示（C8）。
7. 隱藏列：預設跳過並提示筆數，可勾選納入（C9）。
8. 座號：轉整數；非數字或空白 → 沒有座號（交給「自動加入座號」補）；同班重複座號 → 警告「座號 N 重複」，不擋。

**略過的列都要在報告中列出來**（第幾列、原因），老師才相信沒有漏人（`共 34 人，略過 1 列：第 37 列是「平均」`）。

### 4.10 決定班級（O1）

優先順序：`班級` 欄 → 多張工作表時的工作表名稱 → 沒有（視為同一班）。班級名稱只做前後空白、全半形、英文大小寫正規化（C12）。同一人若在班級欄與工作表名稱有衝突，以班級欄為準並提示。

### 4.11 輸出

```
{ roster: [{cls,no,name,score}],          // 與 analyzeRoster / groupRoster 完全相容
  prevGroups: [[studentKey…]…] | null,     // 偵測到「組別」欄時，作為「避免同組」的比對對象（5.7）
  report: {
    sheets: [{name, used, reason}],        // 選了哪些工作表、為什麼
    header: {row, weightRow},              // 標題列與比重列
    columns: [{index, label, role, confidence, why}],
    scoreCols: [...], merge: 'single'|'mean'|'weighted',
    skipped: [{sheet,row,why}],            // 略過的列與原因
    warnings: [{level:'info'|'warn'|'error', text}]
  } }
```

- 偵測到等第或缺考／請假字樣時，出現一個小面板：左邊列出「出現的原文與次數」，右邊每項一個下拉：`沒有成績`／`換算成 N 分`／`當 0 分`。等第預設填入 4.8 的換算表。

### 5.6 不確定時的行為

- 信心「低」或有「無法使用」警告時，「下一步」按鈕旁加一行提示「有 N 項需要確認」，**不擋**，因為老師可能就是要用現狀；但摘要列對應項目標黃色。
- 任何自動判斷都**不會刪掉資料**：被略過的列與換算掉的格子都可在報告中展開看原文。

### 5.7 上次分組（新增的「角色」；使用者已裁示要做，見第 8 節 D3）

- 檔案裡的 `組別`／`分組` 欄＝老師上一次分組結果（O20）。匯入時若偵測到，可選擇「把這欄當作『上次分組』」，轉成 `prevGroups`（成員用 `studentKey`）。
- 在分組方式的「避免與上次同組」比對清單裡多一筆「匯入的分組（來自檔案『組別』欄）」，與程式自己的分組紀錄並列。
- 價值：老師換新學期、換瀏覽器、清掉本機資料，仍能避免同組。成本：多一個角色、多一筆比對來源，需要改設計稿 10.2 的比對清單。

## 6. 兩份檔案對應同一批學生（O19、O20）

> 匯入本身一次只讀一份檔；這一節是「兩個學期要對應同一批學生」時的規則，供「避免同組」匯入和未來比對功能使用。

函式 `matchStudents(A, B)`（A、B 都是 roster）：

1. **主鍵＝班級＋姓名**（正規化後，姓名去空白、NFKC）。班級空白視為同一班。
2. 同班同名（C8）→ 以座號區分；對不上就標「不確定」。
3. 姓名對不上時，**不用座號自動配**（座號會因換座位改變），而是列成「座號相同但姓名不同」警告讓老師看（可能是改名、手誤）。
4. 班級名稱兩份檔不同（例如學年變了）但**姓名重疊 ≥ 80%** → 視為同一班，提示「『X』與『Y』人員重疊 92%，視為同一班」。
5. 輸出：`{ matched, onlyA, onlyB, ambiguous }`。檔案甲↔乙的結果：兩班各 34 人全部 matched、onlyA／onlyB 為空。
6. 轉出（只在舊檔）與轉入（只在新檔）的學生，分別列出，不自動刪或補。

#### 7.5.2 模組內部（由下而上，每一層都能單獨測）

| 層 | 函式 | 輸入 → 輸出 | 對應規則 |
|---|---|---|---|
| 文字 | `norm(s)` | 任意值 → 去前後空白、NFKC、全形空白轉半形的字串 | C3、C7、C12 |
| 文字 | `cleanName(s)` | → 去所有空白（中文名中間的也去）；回 `{ name, note }`，`note` 是被偵測到的註記（不刪） | C7 |
| 讀入 | `decodeCsv(bytes)` | `Uint8Array` → 字串；去 BOM，`TextDecoder('utf-8',{fatal:true})` 失敗改 `'big5'` | C1、D8 |

#### 7.5.3 `opts`：老師修正怎麼帶回來

- 每個自動判斷在 `report` 裡都有固定的鍵；老師在畫面上改了，畫面就把**同一個鍵**放進 `opts.override` 再呼叫一次 `analyze`。沒放的照自動判斷。
- `opts.override = { sheets: ['名稱'…], headerRow: { 工作表名: 列號 }, roles: { '工作表名#區塊#欄號': '姓名'|'座號'|'班級'|'成績'|'上次分組'|'略過' }, scoreMerge: 'mean'|'weighted', grades: { A:95,… }, absent: { '缺': null, '假': 85,… }, includeHidden: false }`
- `analyze` 不保存狀態；同樣的輸入加同樣的 `opts` 一定得到同樣的結果（方便測試與復原）。

#### 7.5.4 上次分組為什麼不直接給 `studentKey`

- `studentKey`＝班級｜座號｜姓名，而座號可能在匯入之後才由「自動加入座號」補上；如果匯入時就算好鍵，補座號後就對不上了。
- 所以 `analyze` 只回 `prevGroupLabels`（與 `roster` 同順序，每人一個組別標籤或 `null`）。等畫面定好名單，再用 `toAvoidGrouping(roster, labels)` 換成鍵。
- 多班時組別標籤以「班級＋組別」區分（甲班第 1 組 ≠ 乙班第 1 組）。
- 「把這筆放進避免同組的比對清單」是分組頁介面的事（施工B範圍，等 D6 設計稿）。

#### 7.5.5 門檻常數（集中一處，數字有理由；調整時要改測試）

| 常數 | 值 | 理由 |
|---|---|---|
| `HEADER_SCAN_ROWS` | 15 | 橫幅加比重列加多層表頭，實務上不會超過 15 列 |
| `NAME_RATIO` | 0.8 | 姓名欄可能夾雜統計列、註記 |
| `SCORE_NUMERIC_RATIO` | 0.5 | 成績欄可能有很多缺考、等第 |
| `FILL_RATE_MIN` | 0.3 | 加扣分欄只填 10～20%（O15） |
| `DUP_SHEET_OVERLAP` | 0.8 | 同一批人換版本時重疊 100%；轉出轉入會差幾個人 |
| `MIN_PEOPLE_FOR_DUP` | 3 | 人太少不判斷重複 |
| 姓名長度 | 2～5 個中文字（可含「·」「．」） | 原住民族、外籍生的名字可能較長，上限放寬到 5，外文名另外判斷 |

#### 7.5.6 訊息文字

- 所有給老師看的字串集中放在 `MSG` 物件（例如 `MSG.dupSheet(name, n)`）；不出現 `#VALUE!` 以外的程式術語。錯誤值原文照錄，因為老師在 Excel 看到的就是它。
- 測試 T20 逐條觸發每一則訊息，並檢查字串裡沒有 `undefined`、`NaN`、`null`。

#### 7.5.7 施工順序與每步的完成條件

1. 文字與讀入層（`norm`、`cleanName`、`decodeCsv`、`fromRows`）→ T8、T9、T13、T15 綠。
2. 表格層（`trimSheet`、`findHeader`、`flattenHeader`、`splitBlocks`）→ T2、T3、T5（區塊）、T6、T17 綠。
3. 欄位層與值轉換（`classifyColumns`、`rankScoreColumns`、`toScore`、`mergeScores`）→ T7、T10、T11、T12、T16 綠。
4. 列與工作表（`pickRows`、`sheetSummary`、`chooseSheets`）→ T1、T4、T5（重複工作表）、T14 綠。
5. 全管線 `analyze`（含 `opts.override`）、`matchStudents`、`toAvoidGrouping` → T18、T19、T20 綠；`analyze` 的輸出餵給 `GroupLogic.analyzeRoster` 與 `groupRoster` 不出錯。
6. `fromSheetJS`：能取得 SheetJS 就測，取不到就標「跳過」（7.3）。
7. 全部綠後：兩份 HTML 相同、既有測試綠、隱私掃描（真實姓名 0 筆）、版號，commit、push、開 PR，回報調度員。

## 8. 裁示結果（2026-11-21）

> 原本是「需要使用者決定的事」，以下是調度員轉達的結果。「使用者」＝使用者本人裁示；「調度員代決」＝調度員依授權決定，使用者可再改。被否決的選項保留在「沒選的選項」欄，給後來的人參考。

| # | 事項 | 結果 | 誰決定 | 沒選的選項（理由） |
|---|---|---|---|---|
| D1 | 檔案有多個工作表 | **自動挑一張並提示**，老師可改選；同一批人重複時只預選一張 | 使用者 | 每次先請老師選（多一步） |
| D2 | 一張表有多個成績欄 | **可把多欄設成「成績」，取平均或加權**；預設優先選最右邊老師算好的「學期成績」這類欄；輸出仍是單一成績 | 使用者 | 只准選一欄（老師要回 Excel 先算） |
| D3 | 檔案裡的「組別」欄 | **匯入成「上次分組」，進「避免與上次同組」比對** | 使用者 | 忽略這欄（換學期或清資料後就無法避開同組） |
| D4 | 缺考、請假 | **預設當沒有成績**，小面板可逐項改成換算分數 | 使用者 | 預設固定分數（老師自己的做法不一致） |
| D5 | 等第換算 | **預設 A95／B85／C75／D65／E55，顯示換算表可改** | 調度員代決 | 不換算（等第檔案就不能按成績分組） |

| D7 | 模擬頁文字「第一個工作表會被讀取」 | **改為「會自動挑選名單所在的工作表」**（隨 D6 設計稿一起改，不在本分支改） | 調度員代決 | 不改（與實際行為不符） |
